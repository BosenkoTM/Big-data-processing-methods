# Лабораторный практикум «Методы обработки больших данных»

**Направление:** 44.03.05 Педагогическое образование  
**Профиль:** «Информатика и дополнительное образование (робототехника)»  
**Среда:** Google Colab

## Сквозная модель

`Sense -> Collect -> Stream -> Store -> Process -> Learn -> Teach`

## Состав

1. `lab_01_spark_batch.md` / `.ipynb` — пакетная обработка PySpark.
2. `lab_02_parquet_benchmark.md` / `.ipynb` — Parquet, partitioning, benchmark.
3. `lab_03_structured_streaming.md` / `.ipynb` — Structured Streaming, event time, watermark.
4. `lab_04_ros2_mcap.md` / `.ipynb` — ROS 2 MCAP/CDR без установленного ROS.
5. `lab_05_timeseries_anomalies.md` / `.ipynb` — временные ряды, Z-score, rolling RMS.
6. `lab_06_mllib_robotics.md` / `.ipynb` — MLlib Pipeline, LeRobot/Open X-Embodiment.
7. `requirements-colab.txt` — фиксированное окружение.

Каждая лабораторная оценивается **ровно в 10 баллов**, из них **2 балла — TEACH CARD**.
